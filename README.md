# NMEA2000 ESP32 - GPS Sportnav SPO25

Simulation et reception de donnees NMEA2000 via CAN bus sur ESP32-S3.

## Projets
- nmea2000_sender : Emetteur NMEA2000 (simule SPO25)
- nmea2000_receiver : Recepteur NMEA2000
- nmea2000_ap : Recepteur + WiFi Access Point + Dashboard web
- nmea2000_udp : Recepteur + UDP broadcast NMEA0183

## Materiel
- ESP32-S3 N16R8
- SN65HVD230 (transceiver CAN)
- Bus NMEA2000 250 kbit/s
